# 开发日志

本目录专门记录 `owoow` 项目的开发过程、问题修复、配置变更和日常操作。
日志按日期归档，路径格式为：

```text
docs/development-log/YYYY/MM/YYYY-MM-DD.md
```

## 维护方式

1. 每天创建一个日期文件；当天的多项事项集中记录在同一个文件中。
2. 开发事项写在“开发记录”下，Git、环境和仓库操作写在“操作记录”下。
3. 事项完成后补充验证结果和后续事项，避免只记录计划而没有结果。
4. 新增日期文件后，在下方“日期索引”中补充链接。

## 日志模板

```markdown
# YYYY-MM-DD 开发日志

## 开发记录

### 事项标题

- 类型：开发 / 修复 / 重构 / 文档
- 分支：`branch-name`
- 变更：
  - 描述变更内容。
- 验证：
  - 描述测试或验证方式。
- 结果：描述完成情况及后续事项。

## 操作记录

### 操作标题

- 类型：Git / 环境 / 发布 / 配置
- 操作：描述执行的命令或步骤。
- 结果：描述执行结果。
- 备注：记录必要的环境信息或风险。
```
